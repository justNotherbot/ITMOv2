# Agent Context

## Project Overview

Цель: разработать образовательный сайт, ясно объясняющий ряды Фурье, полиномы Чебышева и их роль в теории приближенных вычислений. Сайт должен сочетать интерактивные и статические визуализации, поддерживать LaTeX-разметку формул через MathJax и включать понятные графические иллюстрации ключевых идей.

Ключевые разделы сайта:
- Ряды Фурье: интуитивное объяснение разложения функций, частичные суммы, эффект Гиббса, связь с БПФ/ДПФ.
- Полиномы Чебышева: определение, ортогональность, узлы Чебышева, минимизация наихудшей ошибки, полиномы первого и второго рода.
- Приближённые вычисления: интерполяция Чебышева, спектральные методы, аппроксимации Фурье, сравнение ошибок, устойчивость.
- Демонстрации: интерактивные графики (например, построение частичных сумм ряда Фурье и интерполяций на узлах Чебышева).

## Core Requirements

- Бэкенд на Python. Использовать установленный скилл `webapp-testing` для автоматизации локального запуска, smoke-тестов и проверки рендеринга страниц.
- Поддержка LaTeX-формул через интеграцию MathJax на всех страницах, где встречаются формулы. Формулы должны корректно рендериться как в inline (`$...$`), так и в block (`$$...$$`) режимах.
- Понятные графические объяснения с SVG/Canvas-графиками и минимальной интерактивностью: переключатели порядка частичных сумм, количества узлов, выбора базисов и т.д.
- Фронтенд-референс: ориентироваться на шаблон v0 «VII Landing Page» по ссылке: https://v0.app/templates/vii-landing-page-PYPaw4SHrT0?b=b_spB1f8B5lVC (адаптировать структуру секций, типографику и блоки CTA, сохранив академический контент).
- Страницы: Главная, Ряды Фурье, Полиномы Чебышева, Теория приближения, Демонстрации, О проекте.
- SEO/доступность: корректные заголовки, метатеги, ALT-тексты, aria-атрибуты для интерактивных элементов.
- Тестирование: базовые e2e сценарии с `webapp-testing` (доступность главной, наличие ключевых секций, рендер формул MathJax, наличие интерактивных контролов и графиков).

## Technology Stack

- Backend: Python (FastAPI или Flask). Минимальная серверная часть для раздачи страниц и API для данных графиков (например, вычисление частичных сумм/значений полиномов по параметрам).
- Frontend: статические страницы с HTML/CSS/JS; можно использовать небольшой слой на React/Vite при необходимости, но предпочтительно минималистичный стек для ясности. Визуализации через D3.js или Plotly; для простоты допускается Chart.js c кастомными плагинами.
- Math: NumPy/SciPy для вычислений на сервере, при необходимости — WebAssembly/JavaScript реализация для клиентских быстрых демонстраций.
- LaTeX: MathJax 3 (UMD) с настройкой inline- и display-делимитеров.
- Тесты: встроенный скилл `.opencode/skills/webapp-testing` (например, `with_server.py`) для запуска сервера и проверки DOM.
- Dev tooling: uvicorn (если FastAPI), gunicorn (прод), pre-commit linters по желанию.

## Agent Rules & Guidelines

- Архитектура
  - Выбрать один Python-фреймворк (предпочтительно FastAPI) и придерживаться его паттернов. Минимизировать зависимости.
  - Разделить слои: маршруты, шаблоны, полезные математические функции. Сохранять простую структуру: `app/` с `routes`, `templates`, `static`, `math`.

- Реализация визуализаций
  - Использовать SVG/Canvas. Для интерактивности — простые контролы (range/checkbox/select). Обновление графиков — без тяжелых библиотек, если не требуется.
  - Добавить преднастроенные примеры: частичные суммы Фурье для прямоугольного сигнала; интерполяция на узлах Чебышева для гладкой функции; сравнение равномерных vs чебышевских узлов.

- LaTeX/MathJax
  - Подключить MathJax 3 с конфигурацией: inline `$...$` и `\(...\)`, блоковые `$$...$$` и `\[...\]`.
  - Обеспечить отложенную инициализацию при динамическом обновлении контента (перевызов `MathJax.typesetPromise()` после инъекции формул).

- Тестирование с webapp-testing
  - Использовать пример `with_server.py` для запуска сервера в тестах.
  - Автоматизировать проверки: статус-коды 200, наличие элементов `h1/h2`, контейнеров графиков, скрипта MathJax, интерактивных контролов.

- Контент и доступность
  - Сопровождать графики краткими подписями и легендами; использовать понятные оси и сетку.
  - Добавить ALT-тексты и aria-label для элементов управления.
  - Следовать шаблону v0 по структуре секций: hero, features, highlights, demos, call-to-action.

- Производительность
  - Кэшировать серверные вычисления простым LRU для повторяющихся запросов.
  - Избегать избыточной сериализации данных; отправлять только необходимые массивы/параметры.

- Документация и поддержка
  - Описать команды запуска и тестов в README раздела практики.
  - В коммитах фиксировать изменения по секциям/страницам; поддерживать простую, предсказуемую структуру.

Примечание: в качестве фронтенд-референса используется внешний шаблон; при адаптации соблюдать академический стиль, добавить блоки с формулами и иллюстрациями, обеспечить корректную работу MathJax.
