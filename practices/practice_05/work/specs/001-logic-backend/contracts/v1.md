# Calculation API Contract v1

## Endpoint

`POST /api/v1/calculate`

Request JSON:

```json
{
  "operation": "fourier_partial_sum",
  "contract_version": "v1",
  "parameters": {
    "order": 3,
    "x_values": [-1.0, 0.0, 1.0]
  }
}
```

Supported operations are `fourier_partial_sum`, `chebyshev_values`, `chebyshev_nodes`, and `interpolation_comparison`. Parameters are operation-specific as defined in `data-model.md`; unknown fields, non-finite numbers, unsupported enums, invalid intervals, and limits outside the documented ranges are rejected.

## Success Envelope

HTTP `200` returns JSON with:

```json
{
  "operation": "fourier_partial_sum",
  "contract_version": "v1",
  "data": {"x": [-1.0, 0.0, 1.0], "y": [-0.9003163161571061, 0.0, 0.9003163161571061]},
  "metadata": {
    "normalized_parameters": {"order": 3, "x_values": [-1.0, 0.0, 1.0]},
    "domain": {"kind": "periodic", "unit": "radian"},
    "tolerance": {"dtype": "float64", "rtol": 1e-10, "atol": 1e-12},
    "duration_ms": 0.0,
    "cache_status": "miss"
  }
}
```

Operation-specific data may include node arrays, interpolation results, and error summaries, but every success retains the common metadata fields.

## Error Envelope

HTTP `400` or `422` returns:

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "field": "parameters.order",
    "message": "order must be an integer between 1 and 10000",
    "constraint": "1 <= order <= 10000"
  },
  "contract_version": "v1"
}
```

Stable codes include `MALFORMED_JSON`, `VALIDATION_ERROR`, `UNSUPPORTED_OPERATION`, `RESOURCE_LIMIT`, and `NUMERICAL_ERROR`. Server failures must not expose tracebacks, secrets, or arbitrary client expressions.
