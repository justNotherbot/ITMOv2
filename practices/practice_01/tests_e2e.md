# E2E-проверки

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Evidence |
|---|---|---|---|---|
| Позитивный: успешный анализ diff | Авторизация валидна; diff ≤ 20k; LLM отвечает < 10с | POST `/api/reviews` с валидным `diff` | 200, JSON с полями `summary`, `risks` (≤3), `checks`; ссылки на строки diff | Трасс: код ответа, структура JSON, корреляция рисков с diff |
| Негативный: нет поля diff | Авторизация валидна | POST `/api/reviews` с `{}` | 422 Unprocessable Entity | Код ответа 422; тело с деталями валидации |
| Негативный: без авторизации | Нет авторизации | POST `/api/reviews` с валидным `diff` | 401 или 403 | Код ответа 401/403 |
| Граничный: превышение размера | Авторизация валидна; diff длиной 25000 символов | POST `/api/reviews` | 413 Payload Too Large | Код ответа 413 |
| Негативный: таймаут LLM | Авторизация валидна; эмуляция задержки LLM >10с | POST `/api/reviews` | 504 Gateway Timeout или 503 | Код ответа 503/504; лог длительности без содержимого (OBS-1) |
