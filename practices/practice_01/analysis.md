# Анализ процесса: AS IS и TO BE

## AS IS

Событие: разработчик или CI запускает POST `/api/reviews` с JSON телом.
Процесс: контроллер FastAPI принимает `payload: dict`, без валидации достаёт `payload["diff"]` и передаёт в `ReviewService.review`. Сервис формирует `prompt = f"Review...\n{diff}"` и вызывает `llm.generate(prompt)`. Исключения не перехватываются. Нет аутентификации, лимитов размера, таймаутов, редактирования секретов.
Участники: Dev/CI, FastAPI, ReviewService, внешний LLM, человек-ревьюер (после ответа).
Задержки и потери: большие диффы → деградация; отсутствие таймаута → зависание; prompt injection → небезопасный ответ; при отсутствии `diff` → 500.


## TO BE

Минимальный улучшенный поток с контролем ввода/выхода, лимитами и обработкой ошибок согласно CASE.md.

```mermaid
flowchart LR
    A[Dev/CI: POST /api/reviews] --> B[Gateway/Auth\n413 if >20k]
    B --> C[FastAPI: validate\n422 if no diff]
    C --> D[Prompt Builder\nSEC-1 redact]
    D --> E[LLM call\nTimeout 10s]
    E --> F[Error map\n503/504]
    F --> G[OUT-1: summary+risks+checks]
    G --> H[Human review]
```

## Разница

| Что меняется | AS IS | TO BE | Как проверим изменение |
|---|---|---|---|
| Валидация `diff` | Отсутствует, KeyError→500 | 422 при отсутствии/пустоте | E2E: `{}` → 422 |
| Лимит размера | Нет | 413 при >20k символов | Нагрузочный: 25k → 413 |
| Безопасность | Нет | 401/403 при отсутствии токена | Интеграция: без токена → 401/403 |
| Prompt safety | Прямая конкатенация | SEC-1 редактирование + системные инструкции | Юнит: секрет редактируется; инъекция игнорируется |
| Надёжность LLM | Без таймаута/перехвата | Таймаут 10с; маппинг 503/504 | Интеграция: mock timeout → 504 |
| Формат ответа | {comment} | OUT-1: summary, risks<=3, checks | Интеграция: структура и лимиты полей |
