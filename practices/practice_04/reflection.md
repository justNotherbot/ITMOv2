# Рефлексия
## Наблюдения
### Что помогло
1) TDD повышает качество кода, который выдаёт агент
  Задавая чёткие требования на прохождение тестов, мы заставляем агента зацикливаться пока тесты не будут пройдены. Это действительно помогло в разработке проекта.
2) Использование mcp повышает эффективность использования контекста. 
  Из-за того, что агент может перейти напрямую к необходимому ресурсу/тулу, при обработке запроса меньше токенов уходит на подключение зависимостей -> появляется возможность использовать глубину контекста для написания кода/разработки тестов.
### Что помешало
1) Использовался слишком общий MCP. Для моего проекта стоило сначала создать узконаправленный MCP, а потом использовать его для разработки. Это бы сильно повысило эффективность использования контекста.
