# Нагрузочные проверки

| Сценарий | Нагрузка и длительность | Допустимый предел | Что измеряем | Evidence |
|---|---|---|---|---|
| P95 при 256 КБ diff | 5 RPS, 10 мин, diff≈256 КБ | P95 < 1 с | Задержка p50/p95/p99 и среднее (end-to-end), доля 5xx по кодам (500/502/503/504), доля 4xx, число таймаутов клиента, успешность 2xx | Метрики APM/клиента: экспорт percentiles (p50/p95/p99/avg), разбивка ошибок по кодам из access‑логов |
| Лимит размера | 1 RPS, отправка 25k+ символов | 100% 413 | Коды ответов: 200 при ≤ лимита, 413 при > лимита; отсутствие 5xx; p95 задержки для 413 | Логи HTTP/обратный прокси; сэмплы запросов на границе лимита |
| Стабильность таймаута LLM | 1 RPS, инъекция задержки 12 с | 100% 503/504 за ≤11 с | Разбивка 5xx: 503/504 против 500; p95/p99 времени ответа при деградации; число срабатываний таймаута | Логи и трассы: маркер "LLM timeout" и время до ответа, распределение кодов |
