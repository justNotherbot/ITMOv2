# Нагрузочные проверки

| Сценарий | Нагрузка и длительность | Допустимый предел | Что измеряем | Evidence |
|---|---|---|---|---|
| P95 при 256 КБ diff | 5 RPS, 10 мин (прогрев 60 с), diff≈256 КБ, уникальные payload'ы | P95 < 1.0 с; 0% 5xx; timeouts клиента = 0 | 95-й перцентиль server-side latency по успешным 2xx (от принятия запроса до отправки последнего байта); доля ошибок: 4xx по типам 400/401/403/404/413/422 и 5xx по типам 500/502/503/504; % таймаутов клиента | Отчёт hey/vegeta (latency p95, распределение кодов); access-логи Uvicorn с временем обработки и кодами; при наличии — трассы OpenTelemetry |
| Лимит размера входа | 1 RPS, 100 запросов, diff от 256 КБ до 2 МБ | ≥99% HTTP 413 без обращения к LLM; TTFB < 100 мс | Код ответа (ожидаем 413 Payload Too Large); отсутствие вызова review_service (по маркерам логов); латентность до отбивки 413 | Access-логи с кодом 413 и отсутствием внутренних логов review_service; отчёт клиента с распределением кодов |
| Таймаут LLM и деградация | 1 RPS, 30 запросов, искусственная задержка LLM 12 с | 100% 503/504 за ≤11 с, без зависаний; очередь не растёт | Коды 503/504; фактическое время завершения запроса ≤ 11 с (server-side); отсутствие 500; размер очереди воркеров/соединений | Логи с таймстемпами начала/окончания и кодами; отчёт клиента; при наличии — трассы span'ов |

Как измеряем время ответа: используем server-side latency по access-логам (время обработки запроса приложением) и клиентскую латентность из отчёта генератора нагрузки; для расчёта P95 берём только успешные 2xx ответы после прогрева. Ошибки: фиксируем отдельно 4xx (400/401/403/404/413/422) и 5xx (500/502/503/504), а также таймауты клиента. Для сценария с таймаутом LLM задержка эмулируется заглушкой/настройкой тестового окружения, без изменения боевого кода.

Если нагрузочное тестирование пока не требуется, обосновываем: сервис не доступен внешним потребителям и используется эпизодически (≤1 RPS) в не‑прод окружении. Запуск обязателен перед пилотом/продакшеном, при изменении `review_service` или политики лимитов, а также при росте ожидаемой нагрузки.
